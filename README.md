# hotelbooking\_application\_1

A new Flutter project# BookMyStay - Hotel Booking App



A Flutter hotel booking application featuring a luxury-inspired design.



\## Features



\- Destinations

\- Hotels

\- Experiences

\- Special offers

\- Login and user registration

\- Firebase integration

\- Responsive layouts

\- Reusable Flutter components



\## Technologies



\- Flutter

\- Dart

\- Firebase

\- Cloud Firestore



\## Getting Started



1\. Install Flutter and Dart.

2\. Clone this repository.

3\. Run `flutter pub get`.

4\. Run `flutter run`.
